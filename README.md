# Barrancas del Cobre — Proyecto VIA-BC

Registro fotográfico del viaje por la sierra Tarahumara, del 21 al 26 de junio de 2009:
del Ángel de Chihuahua al fondo de la barranca de Urique. Cada lámina conserva su ficha
documental completa, en orden cronológico según los datos EXIF de captura.

Esta edición web recoge 80 láminas del expediente. Las fotografías con personas
identificables no se publican, y las fichas no incluyen nombres de personas.

El álbum se genera desde el expediente del proyecto con `generar_album.py`.
Este repositorio contiene únicamente la salida web: `index.html` y la carpeta `img/`.
